# Flame Connect Card 0.4.1

## Native controls dialog

Pressing the fireplace chip icon or summary now opens its controls in a native modal by default. The dashboard chip keeps its height, and no Browser Mod installation is required. Close the dialog with Escape, its close button or a backdrop click; keyboard focus returns to the chip, including in Safari.

The dialog and chip share entity bindings, visibility preferences, pending commands and confirmed state. Opening or closing never replays an action. Reconfiguration and removal close the dialog.

## Mushroom-style proportions

The chip uses native Home Assistant MDI icons, 36 px icon containers and action buttons, 20 px icons, 14/12 px primary/secondary text and compact spacing. Active effects retain orange highlighting; confirmed standby remains gray.

## Configuration and upgrade

- New `chip_expansion` setting: `modal` (default) or `inline`.
- Choose **Chip expansion → Dialog** in the visual editor, or use `chip_expansion: modal`.
- Choose **In dashboard** (`inline`) to retain the previous inline chip expansion.
- The standard compact layout continues to expand inside the dashboard.
- The editor supports English and Spanish. Documentation and previews are updated.

Update through HACS and reload the Home Assistant frontend. Manual installations should replace the attached `flame-connect-card.js` and reload the frontend. Minimum supported Home Assistant version remains **2026.10.4**.

This is an unofficial card designed for the [Flame Connect HA integration](https://github.com/smarquina/Flame-Connect-HA).
