# Flame Connect Card 0.4.0

## New compact chip

Choose **Compact style → Chip** in the visual editor for a horizontal fireplace summary with a name, current state and independent flame and heating buttons. The fireplace icon is gray when both effects are confirmed off and orange when either is on. Unknown effects display a warning; confirmed whole-device standby takes precedence.

Press the summary to expand the same card. The action buttons control their respective effects without expanding the card or changing the other effect. Expanded view retains whole-device power and all configured detail controls. Fan-only operation is identified as ventilation.

## Configuration and compatibility

- New `compact_style` setting: `standard` (default) or `chip`.
- Existing configurations retain their current presentation.
- Chip mode shares entity mappings, visibility preferences and command confirmation with expanded view.
- Compact thumbnails and detail selections remain saved but are not displayed in chip mode.
- Keyboard focus is preserved when expanding and collapsing. The editor and action labels support English and Spanish.

```yaml
initial_view: compact
compact_style: chip
```

Update through HACS and reload the Home Assistant frontend. Manual installations should replace `flame-connect-card.js` and reload the frontend. Minimum supported Home Assistant version remains **2026.10.4**.

This is an unofficial card designed for the [Flame Connect HA integration](https://github.com/smarquina/Flame-Connect-HA).
