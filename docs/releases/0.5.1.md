# Flame Connect Card 0.5.1

## Fix: action buttons with card-mod

Flame, heating and whole-device power buttons now adapt their background to the card's primary text color. This fixes white buttons on translucent dark cards styled with card-mod 0.5.0. The chip's fireplace icon background adapts in the same way. Active action icons use the card's primary color; the main fireplace status icon retains its separate activity color.

Existing card-mod YAML that sets `--primary-text-color`, `--primary-color` and the card background works without additional button-specific CSS. The card also accepts Mushroom's `--chip-background` and these optional overrides:

- `--fireplace-action-background` and `--fireplace-action-active-background`
- `--fireplace-action-color` and `--fireplace-action-active-color`
- `--fireplace-icon-background`

Use the stable `data-action` selectors `flame`, `heating` and `power` to style controls individually. See the [configuration guide](https://github.com/smarquina/flame-connect-card/blob/main/docs/configuration.md#styling-action-buttons) for examples. Both the chip and the expanded dialog use these styles.

## Upgrade

Update through HACS and reload the Home Assistant frontend. Manual installations should replace the attached `flame-connect-card.js` and reload the frontend. Minimum supported Home Assistant version remains **2026.10.4**. card-mod remains an optional, separately installed integration.

This is an unofficial card designed for the [Flame Connect HA integration](https://github.com/smarquina/Flame-Connect-HA).

## Validation

241 unit/component/contract tests passed with 100% line, branch, statement and function coverage. The browser suite covers 112 cases across Chromium, mobile Chromium, Firefox and WebKit. An isolated Chromium test loaded the official card-mod 4.2.1 module with a simulated Home Assistant context and verified the reported dark glass CSS, action colors and modal. Tests use simulated entities; actual appearance depends on the user's theme and card-mod configuration.
